This project is a work in progress. As someone interested in Agentic AI, I personally find it helpful to understand how popular agentic frameworks -- especially real-world-adjacent ones like Meta Muse, OpenAI Dots, or Instinct -- are built out.

At various stages, this project may look like it's treading over known ground. The goal isn't to develop something novel from the start but to develop a strong foundation for future ventures.

This is meant to be run on my current open-source AI. Right now, frontier cloud models still dominate the hardest jobs. Yes, I'm using frontier AI to help me build this project. But at this rate of progress, I believe the use of personal AI computers to become rapidly more relevant in the next 5-10 years, if not sooner.

Feel free to follow along on my journey!!
