The Design Philosophy of this Website

The secret is... there is no secret. The form of this website came from two undeniable facts:

  1. I want to feel like I OWN this website
  2. I have neither the time nor the particular inclination to learn something like WordPress or spend a lot of time designing a website

My goal is to have a simple, universal interface that works anywhere, with anyone, and that I feel comfortable editing personally without having to sift through 3000 lines of AI-generated code that may-or-may-not-work.

Maybe one day, I'll find the time to pretty it up, so to speak. But for now, I think the content is there. There are plenty of pretty websites out there to look at, if you want. This one ain't all that, but it's mine. Welcome!!
