Pixel Game

A just-for-fun DIY version of popular app store game "Jewel Coloring." Fun pastime currently served live. Major upgrades include:

  1. custom puzzle creation by sending your prompt directly to a pipeline powered by a local image model
  2. friends you can add and send custom puzzles to
  3. no ads, cookies, or profitability-related shenanigans
  4. easy way to contact the head developer (me) for any suggestions or changes

Unfortunately, perks 1-2 are currently on an invite-only basis as I don't want to deal with the headaches of turning a simple game into a scalable multiplayer service at the moment, but the rest of it is great!! Currently served live at momoswebsiteofthehour.com (excuse the domain name)

The Design Philosophy of this Website

The secret is... there is no secret. The form of this website came from two undeniable facts:

  1. I want to feel like I OWN this website
  2. Learning something like WordPress or spending a lot of time designing a website is not currently in my list of priorities

My goal is to have a simple, universal interface that works anywhere, with anyone, and that I feel comfortable editing personally without having to sift through 3000 lines of AI-generated code that may-or-may-not-work.

Maybe one day, I'll find the time to pretty it up, so to speak. But for now, I think the content is there. There are plenty of pretty websites out there to look at, if you want. This one ain't all that, but it's mine. Welcome!!
